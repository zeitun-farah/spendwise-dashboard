# SpendWise Dashboard

SpendWise is a modern and responsive personal finance dashboard built with HTML and CSS.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Dashboard header and user profile
- Six financial category cards
- CSS Grid for the main layout
- Flexbox for navigation, header, and cards
- CSS custom properties for theming
- Responsive design for smaller screens
- Hover and keyboard-focus card animations
- Dark theme support using `prefers-color-scheme`

## Financial Categories

The dashboard includes:

- Food
- Transport
- Rent
- Entertainment
- Savings
- Utilities

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Responsive Media Queries
